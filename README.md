# Scam Alert — Pakistan

Ek free tool jisse koi bhi shak wale number, website link ya message ko check kar sakta hai — aur agar scam ho jaye to FIA shikayat ka tayyar text bana sakta hai.

## Kya kya hai

- **Scam Checker** — number, link ya message paste karo: 25+ red-flag patterns, brand-impersonation aur mashhoor scam sites ki check ke baad **risk score 0–100** aur saaf mashwara milta hai.
- **6 scam types ki guide** — Task/Job scam, Fake Investment, OTP Call, Fake Store, SIM VAS Trap, Prize scam — filter karke parho.
- **Red flags ki list** — wo nishaniyan jin se scam pehchana jata hai.
- **5 emergency steps** — agar scam ho jaye to foran kya karna hai.
- **Report Builder** — apni shikayat ka tayyar FIA complaint text banata hai; copy karo ya .txt me download karo.
- **Rabatay** — FIA Cybercrime **1991**, PTA **0800-256813**.

## Ehem baat (saaf saaf)

Ye checker **pattern-based andaza** lagata hai — koi live database nahi hai. Report Builder sirf shikayat ka text banata hai; tumhari report doosre logon ko nazar nahi aati. Kisi bhi number ya website ko "scam" kehne se pehle saboot check karo.

## Kaise use karein

`index.html` ko browser me kholo — koi install nahi chahiye. Ya GitHub Pages par host karke link share karo.

## Kaise bana hai

Sirf HTML, CSS aur JavaScript — koi server nahi, koi database nahi. Tumhara data tumhare browser me hi rehta hai, kahin save ya bheja nahi jata.
